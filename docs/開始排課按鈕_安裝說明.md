# 「開始排課」按鈕　安裝說明

裝好之後，在 Google 試算表按「排課系統 → ▶ 開始排課」，約 1～3 分鐘，課表就會自動寫回試算表。
**全程用瀏覽器點選，不用打指令。只要裝一次。**

## 運作方式

```
Google 試算表（真實資料，只有學校帳號看得到）
   │ ① 按「開始排課」→ 通知 GitHub
   ▼
GitHub（公開的排課程式）
   │ ② 帶通關密語來拿資料 —— 老師姓名已換成 T001、T002… 代號
   │ ③ 用 OR-Tools 排課（約 5～60 秒）
   │ ④ 把結果送回來
   ▼
Google 試算表：把代號換回真名，寫進「排課結果」「老師課表」「規則體檢」
```

**隱私**：真實姓名只留在試算表；GitHub 只看到代號，執行紀錄也不印任何資料內容。

## 安裝步驟

### 第 1 步：建立試算表
1. 把 `收集表/115_10_排課需求收集表.xlsx` 上傳到 Google 雲端硬碟
   （想先試用，可改用 `試跑/試跑資料_排課需求收集表.xlsx`）
2. 在檔案上按右鍵 →「選擇開啟工具」→「Google 試算表」
3. 「檔案」→「儲存為 Google 試算表」

### 第 2 步：貼上程式
1. 在試算表按「擴充功能」→「Apps Script」
2. 刪掉編輯器裡原本的內容，把 [`apps-script/排課系統.gs`](../apps-script/排課系統.gs) 全部複製貼上
3. 按「儲存」（磁碟片圖示），關掉 Apps Script 分頁
4. 回到試算表按重新整理，上方會出現「排課系統」選單

### 第 3 步：初次設定
按「排課系統 → 初次設定」，右邊會出現設定面板，照面板上的 ①～④ 做：
1. **部署成網頁應用程式**（執行身分：我；誰可以存取：所有人）
2. **取得 GitHub 金鑰**（Contents：Read and write），貼進面板、按「儲存並測試」
3. **把網址和通關密語貼到 GitHub Secrets**（名稱分別是 `SCHED_URL`、`SCHED_KEY`）
4. 按「▶ 開始排課」試試看

## 選單功能

| 選單 | 做什麼 |
|---|---|
| ▶ 開始排課 | 依規則表排出全校科任課表，結果寫回試算表 |
| 查看課表（網頁） | 在試算表裡開啟漂亮的課表檢視（班級／老師／專科教室／規則體檢） |
| 查看排課進度 | 顯示目前是送出、計算中、完成或失敗 |
| 初次設定 | 設定 GitHub 金鑰、看通關密語 |

排課會新增或覆蓋這幾張工作表：**排課結果**（全校班級）、**老師課表**、**規則體檢**、**排課紀錄**（每次排課的時間與結果）。

## 常見問題

- **按了之後一直「計算中」**：開 https://github.com/ntpsbing/course-scheduling/actions 看最新一次執行有沒有紅色叉叉。
- **「GitHub 金鑰無效或過期」**：金鑰最長一年，到期在「初次設定」換一把新的。
- **改了 Apps Script 程式之後沒效果**：要「部署 → 管理部署作業 → 編輯 → 版本選『新版本』→ 部署」，網址不會變。
- **交接給下一任**：把試算表與 Apps Script 的擁有權轉給新承辦人，新承辦人重做第 3 步（換成自己的 GitHub 金鑰）。
