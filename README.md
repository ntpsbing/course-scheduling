# 楠梓國小排課系統

高雄市楠梓區楠梓國小 115 學年度起使用的**科任排課系統**。
目標：完成全校科任老師的排課，滿足老師的需求，讓課程順暢；**操作簡單、老師好上手、日後交接容易**。

🌐 **系統首頁**：https://ntpsbing.github.io/course-scheduling/

---

## 這個系統做什麼
- **只排科任課**。排好後，剩下的節次由導師自己排。
- 每班課表會分成三種格子：✅ 已排好的科任課、🔒 保留給導師的課（會寫明科目，例如特教抽離時段）、⬜ 導師自由排。
- 系統會檢查每班剩下的格子數，是否剛好等於導師要上的節數。

## 排課規則：四層，由上往下處理
| 層級 | 意思 | 內容 |
|---|---|---|
| ⚖️ 0 法規 | 教育局、教育部規定，最優先 | 職務不排時段、第七節不排正課（國數英社自） |
| 🔒 1 鎖定 | 先鎖住、系統不動 | 本土語（學校預排）、特教抽離、三四年級星期一下午綜合、五六年級星期四下午綜合、星期三第一節綠色迪士尼、低年級下午 |
| ⛔ 2 必須 | 不能違反 | 同一位老師同一節只能在一個班、專科教室間數、自然 2 節連堂＋1 節原班、老師勾「必須」的時段（每人最多 3 節） |
| 💡 3 盡量 | 盡量做到 | 體育不排第四五節、每天 6 節以下、跑班距離盡量近、老師勾「希望」的時段 |

完整規則與設計說明：[docs/排課規則與設計.md](docs/排課規則與設計.md)

**新增規則不用改程式**：在「規則表」加一列、選下拉選單就好；暫停規則把「啟用」改成「否」。

## 交接給下一任
1. 規則、名單、權限都在試算表裡，不藏在程式中。
2. 每條規則都有「原因」欄；職務限制有「依據文號」欄。
3. 換學期：更新配課、職務名單、老師需求，規則沿用。
